# Sounds

The sound effects a film's scene names (`sound.at(time, 'thud')`), each an Ogg
Vorbis file read as a declared resource. All are from Kenney's audio packs
([kenney.nl](https://www.kenney.nl)), released under Creative Commons Zero
([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)): free to use in any
project, credit appreciated but not required.
