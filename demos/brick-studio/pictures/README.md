# Pictures

The pictures Brick Studio ships for its example films, by name (`image:
'see-america-montana'` stands `see-america-montana.jpg`): every image in this folder,
which the manifest declares as the resource folder `picture/`. A file added here is a
shipped picture, nothing else to change. A build of your own shows any image in the
Platform by its `charmiq://file/<assetId>` URI: one you upload, one a Charm downloads,
or one it generates.

Each is in the public domain, scaled to 640 pixels high from its source.
